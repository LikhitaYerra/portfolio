# Likhita Yerra · Portfolio

Personal site for GitHub Pages: research, selected public projects, and experience.

**Live:** https://likhitayerra.github.io/portfolio/

## Structure

- `index.html`: all content (hero, about, spotlight, projects, publications, experience, skills, certificates, contact)
- `styles.css`, `script.js`: styling, scroll reveal, active-section nav
- `assets/Likhita_Yerra_CV.pdf`: CV linked from the hero, nav and contact section
- `assets/og.png`: 1200x630 link-preview image used by the Open Graph / Twitter tags

## Updating

- Publication status chips (Submitted, Presenting, Presented, Accepted, Published) live in `.pub-venue` in `index.html`. Change the chip text when a status changes.
- When the CV changes, copy the new PDF over `assets/Likhita_Yerra_CV.pdf`.
- The Emergency Response Twin demo runs on a free Render instance that sleeps when idle, so the first visit can take up to a minute.

## Content rules

- Employment listed: IAware/amzilai and AIRecruiter only.
- AI Clinic partner work is labelled as aivancity school projects, not employment.
